# Getting Started

The fastest path from zero to a working DeDi integration.

Follow the [Quickstart](quickstart) to validate your first schema payload and issue your first query — it takes about 10 minutes.

Once you have the basics, choose the path that matches your role:

- [Implement](../implement) to build or integrate;
- [Operate](../operate) to publish and run directory infrastructure;
- [Verify](../verify) to make reliance decisions;
- [Test](../test) to exercise conformance and inspect evidence; or
- [Understand](../understand) for architecture, governance, and interoperability context.
